## 1. Overview

**DC Detailing** is a modern booking engine and service presentation platform designed for a high-end mobile automotive care and ceramic coating studio. Moving away from clunky enquiry forms and phone-tag scheduling, DC Detailing gives vehicle owners immediate clarity on packages, vehicle-tier pricing, and calendar slot reservations.

The platform includes a real-time price calculator according to car category, interactive date and time slot pickers, digital detailing gift cards, and a live administrative dashboard for managing appointments and field technicians.

---

## 2. Key Features

- **Dynamic Tier-Based Price Calculator:** Instant package calculation across vehicle segments (Hatchback / Compact Sedan, Mid-size Sedan, Compact SUV, Full-size SUV / Luxury).
- **Comprehensive Service Menu:** Transparent breakdowns of Exterior Foam Wash, Interior Deep Clean & Steam Sterilization, Multi-Stage Paint Correction, and 1 to 5-Year Ceramic & Graphene Coating packages.
- **Interactive Appointment Booking:** Frictionless scheduling workflow allowing customers to select dates, preferred service time windows, address location, and add-on services.
- **Digital Gift Card Purchase & Redemption:** Gift card purchase module with custom denomination selection, recipient messaging, and validation checking.
- **Admin Management Console (`admin.html`):** Operational dashboard for detailing managers to view calendar schedules, dispatch mobile teams, update booking statuses, and inspect revenue tallies.
- **Dark Gloss Automotive Aesthetics:** High-contrast carbon and dark metallic UI design language tailored to automotive detailing enthusiasts.
- **Responsive Layout:** Engineered for quick booking directly from smartphones, tablets, and desktop workstations.

## 5. Getting Started

### Local Setup
This project runs as a static web application with optional Vercel CLI functions:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/diu-ctrl/Detailing-Cars.git
   cd Detailing-Cars
   ```

2. **Serve locally:**
   Run any static web server in the project directory:
   ```bash
   # Using npx serve:
   npx serve .

   # Or using Python:
   python -m http.server 3000
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
